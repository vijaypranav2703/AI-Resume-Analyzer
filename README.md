# AI Resume Analyzer

This is a simple AI Resume Analyzer project built using Python and Streamlit. The project helps compare a resume with a job description and provides insights about skill matching, missing skills, and overall suitability for a role.

## Features

* Upload resumes in PDF format
* Extract text from resumes automatically
* Detect technical skills from resume content
* Compare resumes with job descriptions
* Calculate Text Similarity Score
* Calculate Skill Match Score
* Identify missing skills
* Provide learning suggestions
* Generate career recommendations
* Display analysis results in an interactive dashboard

## Technologies Used

* Python
* Streamlit
* PDFPlumber
* Scikit-Learn
* TF-IDF Vectorization
* Cosine Similarity

## Project Workflow

1. Upload a PDF resume
2. Paste a job description
3. Extract resume content
4. Detect technical skills
5. Compare resume and job description
6. Generate match scores
7. Display missing skills and recommendations
